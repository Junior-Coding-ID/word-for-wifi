## Entry

**Theoretical**

One word for your Wi-Fi — the network name is a single word: `Theoretical`.

## How it works

`main.ts` writes the entry word plus a trailing newline to `entry.txt`
inside the output directory (`process.env.MAKEFUN_OUTPUT`, default `/output`).

Run it with:

```sh
node main.ts
```
